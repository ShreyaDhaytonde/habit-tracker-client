# Habit Tracker

Next.js frontend for tracking daily habits and streaks. Talks to the
[habit-tracker-server](https://github.com/ShreyaDhaytonde/habit-tracker-server) API.

## Run locally

```bash
npm install
cp .env.local.example .env.local   # points at the API, defaults to http://localhost:8000
npm run dev
```

## Test

```bash
npm test
```
